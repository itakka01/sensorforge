SensorForge OV3660 Sensor Crop release
Baseline: user files uploaded 2026-09-10 07:19:07

Functional changes:
- itakka_sensorcam.ino: OV3660 runtime raw sensor crop + persisted crop application after camera init.
- config.cpp/config.h: optional backward-compatible camera_crop_zoom/x/y config + crop-only save helper.
- webconfig.cpp: Live Preview 1.0x/1.5x/2.0x crop selection, 3x3 position grid, test-before-save, fail-safe restoration of unsaved crop.
- config.txt: adds camera_crop_zoom=1.0, camera_crop_x=1, camera_crop_y=1. All other user values preserved.
- camera_select.h: included for reference; byte-identical to uploaded file.
- webplayer.cpp/.h: not changed and intentionally not included.

Safety/backward compatibility:
- Missing crop keys default to 1.0 / center / center.
- 1.0x cold boot leaves the legacy camera init geometry path untouched.
- Runtime crop only applies when the detected PID is OV3660 (0x3660).
- Unsaved Live Preview crop is restored before automatic recording can resume.
- Crop is limited to 4:3 outputs up to 1024x768 in this release.
- Existing recording_event_max_seconds=65 and recording_event_cooldown_seconds=120 from the supplied config are preserved.
